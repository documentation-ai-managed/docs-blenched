## Overview

Blenched provides a streamlined authentication platform centered around Google Sign-In. You integrate it into your web or mobile applications to handle user logins securely without building complex auth flows from scratch. Access protected resources effortlessly once users authenticate via their Google accounts.

The platform manages OAuth tokens, user sessions, and account linking, reducing your development time significantly. Focus on your core features while Blenched handles the security and compliance aspects of authentication.

## Quick Start

Get up and running in minutes:

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up at `https://dashboard.example.com` using your Google account.
  </Step>
  <Step title="Get API Key" icon="key">
    Generate your key from the dashboard settings.
  </Step>
  <Step title="Integrate Sign-In">
    Add the Google Sign-In script and initialize Blenched.

    <CodeGroup tabs="JavaScript,Python">
      ```javascript
      // Load Google API
      gapi.load('auth2', () => {
        gapi.auth2.init({
          client_id: 'YOUR_GOOGLE_CLIENT_ID',
          hosted_domain: 'example.com'
        }).then(() => {
          // Sign in with Blenched
          gapi.auth2.getAuthInstance().signIn({
            scope: 'profile email'
          }).then(googleUser => {
            fetch('https://api.example.com/auth/google', {
              method: 'POST',
              headers: { 'Content-Type': 'application/json' },
              body: JSON.stringify({
                id_token: googleUser.getAuthResponse().id_token
              })
            });
          });
        });
      });
      ```
      ```python
      import requests

      # Exchange Google token with Blenched
      response = requests.post(
          'https://api.example.com/auth/google',
          json={'id_token': 'google-id-token-here'},
          headers={'Authorization': 'Bearer YOUR_API_KEY'}
      )
      print(response.json())
      ```
    </CodeGroup>
  </Step>
</Steps>
