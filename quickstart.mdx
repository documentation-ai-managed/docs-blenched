## Prerequisites

Before you begin, ensure you have a Google account ready for sign-in. Blenched uses Google authentication for secure, seamless access.

<Callout kind="info">

**Requirements:**
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Stable internet connection
- Google account with two-factor authentication enabled (recommended)

</Callout>

## Create Your Blenched Account

Sign up takes under a minute using Google sign-in. Follow these steps to get started.

<Steps>
  <Step title="Visit Blenched Login" icon="external-link">
    Open your browser and navigate to `https://blenched.com/signin`.
  </Step>
  <Step title="Select Google Sign-In" icon="apple">
    Click the **"Continue with Google"** button on the login page.
  </Step>
  <Step title="Authorize Blenched" icon="shield">
    Review permissions and click **"Allow"** to grant Blenched access to your basic Google profile information.
  </Step>
  <Step title="Access Dashboard" icon="dashboard">
    You land on the main dashboard automatically upon successful authentication.
  </Step>
</Steps>

## Complete Initial Setup

Configure your profile to personalize your experience.

<Steps>
  <Step title="Update Profile" icon="user">
    Click **Profile** in the navigation. Edit your display name, avatar, and preferences.
  </Step>
  <Step title="Verify Email" icon="check-circle">
    Check your Google-associated email for a verification link from Blenched.
  </Step>
  <Step title="Set Preferences" icon="settings">
    In **Settings**, enable email notifications and select your time zone.
  </Step>
</Steps>

<Expandable title="Advanced Setup (Optional)" default-open="false">

For developers, update your profile via API:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.example.com/v1/profile', {
    method: 'PATCH',
    headers: {
      'Authorization': `Bearer YOUR_TOKEN`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      displayName: 'Your Name',
      preferences: { notifications: true }
    })
  });
  ```
  ```python
  import requests

  response = requests.patch(
    'https://api.example.com/v1/profile',
    headers={
      'Authorization': 'Bearer YOUR_TOKEN',
      'Content-Type': 'application/json'
    },
    json={
      'displayName': 'Your Name',
      'preferences': {'notifications': True}
    }
  )
  ```
</CodeGroup>

</Expandable>

<Callout kind="tip">

Save your profile changes. You now have full access to Blenched features.

</Callout>
